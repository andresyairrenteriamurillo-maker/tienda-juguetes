Conecta tu tienda

Para guardar productos, este panel necesita una llave de acceso de GitHub con permiso solo para tu tienda. Se crea una vez y queda guardada únicamente en este dispositivo.

Solo se hace una vez por dispositivo:

  1. Crear mi llave en GitHub
    Se abre con el nombre, la duración (1 año) y el permiso ya puestos.
  2. En Repository access toca Only select repositories y elige tienda-juguetes.
  3. Baja hasta el final, pulsa Generate token y copia la llave.
  4. Vuelve aquí, pégala abajo y pulsa Conectar.
