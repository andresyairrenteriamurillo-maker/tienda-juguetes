Conecta tu tienda

Para guardar productos, este panel necesita una llave de acceso de GitHub con permiso solo para tu tienda. Se crea una vez y queda guardada únicamente en este dispositivo.

Cómo crear la llave (2 minutos)
  1. Abre github.com/settings/personal-access-tokens/new con tu cuenta de GitHub.
  2. En Token name escribe «Panel tienda». En Expiration elige el tiempo que quieras (por ejemplo 1 año).
  3. En Repository access elige Only select repositories y selecciona tienda-juguetes.
  4. En Permissions → Repository permissions → Contents elige Read and write.
  5. Pulsa Generate token, copia la llave (empieza por github_pat_) y pégala aquí abajo.
